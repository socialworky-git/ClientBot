Canvas Quiz Builder

Turn a quiz you already wrote into a file Canvas can import.

Turn a quiz you already wrote into a package Canvas can import. Paste it in, or drop in a Word document, PDF, Excel sheet, or CSV, in whatever layout you already have. Fix anything that came through wrong, then download the file and upload it to your course.

Free and no account needed. Tidy text is read right in your browser. Anything messier is read by an AI model, which sees your quiz once and does not keep it.

1. Bring in your quiz

Bring it in however you have it. Numbered questions, a Canvas or Respondus CSV export, a spreadsheet with one question per row, or a Word or PDF file. If the layout is one the page recognizes, it reads it instantly in your browser. Otherwise it hands the text to the AI reader, which is built for messy input.

2. Check your questions

Click any line to edit it. The green marker is the answer Canvas will score as correct. Anything highlighted in amber needs attention before you export.

3. Settings and download

These become the quiz settings in Canvas, and you can change all of them after importing.

Getting the file into Canvas

You will download a .zip file. Leave it zipped. Canvas needs it that way, and on a Mac it is easy to double click it by accident.

  1. Open the Canvas course and click Settings in the course menu.
  2. On the right side, click Import Course Content.
  3. For content type, choose QTI .zip file.
  4. Click Choose File and pick the zip you downloaded.
  5. Leave the checkboxes alone and click Import.
  6. Wait for the job to finish, then open Quizzes. Your quiz is there as an unpublished draft.
Leave "Overwrite assessment content with matching IDs" unchecked. Checking it tells Canvas to replace existing content that shares an ID, and there is no undo. Every file this tool builds gets a fresh ID, so an import always makes a new quiz and never touches what is already in your course.

After the import

Open the quiz and click Edit to set the due date, time limit, and availability. Canvas imports quizzes unpublished, so students cannot see it until you publish. Preview it once before you do.

If you want students to see the rationale

Rationale text lands in the general answer comment, which Canvas shows every student after they submit, whatever they picked. For that to appear, the quiz has to let students see their responses. In the quiz edit screen, check Let Students See Their Quiz Responses. For a practice quiz this is usually what you want.

Question types it builds

Multiple choice, true/false, multiple answers, short answer, and essay. Matching, ordering, and file upload questions are not supported, so add those by hand after importing.

If something looks wrong

The most common cause is an answer key the tool could not connect to the questions. Watch the message after step 1: it tells you how many key entries it matched. If that number is lower than your question count, some items came through with no correct answer marked, and those get highlighted in amber in the review list. Fix them there before you export.

About your quiz content. Editing and building the file happen in your browser, and so does reading when the layout is one the page recognizes. When the AI reader is used, the quiz text is sent once to Socialworky's server, relayed to the model, and returned as structured questions. It is not stored or logged. Everything you download stays on your computer.
