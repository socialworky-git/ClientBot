Canvas Quiz Builder

Turn a quiz you already wrote into a file Canvas can import.

Turn a quiz you already wrote into a package Canvas can import. Paste it in, or drop in a Word document, PDF, Excel sheet, or CSV. Fix anything that came through wrong, then export in whatever format you need.

Free and no account needed. Your draft is saved in this browser — nothing is stored on this site. Tidy text is read right in your browser. Anything messier is read by an AI model, which sees your quiz once and does not keep it.

1. Bring in your quiz

Paste numbered questions, drop in a Word or PDF file, or paste rows straight from a spreadsheet. If the layout is one the page recognizes, it reads it instantly in your browser. Otherwise it hands the text to the AI reader.

Getting the file into Canvas

You will download a .zip file. Leave it zipped. Canvas needs it that way, and on a Mac it is easy to double click it by accident.

  1. Open the Canvas course and click Settings in the course menu.
  2. On the right side, click Import Course Content.
  3. For content type, choose QTI .zip file.
  4. Click Choose File and pick the zip you downloaded.
  5. Leave the checkboxes alone and click Import.
  6. Wait for the job to finish, then open Quizzes. Your quiz is there as an unpublished draft.
About "Overwrite assessment content with matching IDs." The builder now saves a stable identifier with each quiz file. If you save a quiz file and re-import it later, checking this box will replace the earlier version of the same quiz. Leave it unchecked if you want a new copy each time.

Paper and study page exports

The Printable quiz and Answer key buttons open a print dialog — choose "Save as PDF" to download a file. The quiz paper uses the same Letter layout as the Word document. The study page is a self-check HTML file you can share by link or upload anywhere — students click an answer and see whether they got it right, along with the rationale and the "Where to find it" note.

After the import

Open the quiz and click Edit to set the due date, time limit, and availability. Canvas imports quizzes unpublished, so students cannot see it until you publish. Preview it once before you do.

If you want students to see the rationale

Rationale text lands in the general answer comment, which Canvas shows every student after they submit, whatever they picked. For that to appear, the quiz has to let students see their responses. In the quiz edit screen, check Let Students See Their Quiz Responses. For a practice quiz this is usually what you want.

Question types it builds

Multiple choice, true/false, multiple answers, short answer, and essay. Matching, ordering, and file upload questions are not supported, so add those by hand after importing.

About your quiz content. Editing and building the file happen in your browser. The draft is saved in this browser only — nothing is stored on this site. When the AI reader is used, the quiz text is sent once to Socialworky's server, relayed to the model, and returned as structured questions. It is not stored or logged. Everything you download stays on your computer.
